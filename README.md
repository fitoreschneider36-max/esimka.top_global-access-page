# esimka Global Access Page

这是一个独立的 GitHub Pages 落地页，用于集中宣传 `esimka.top` 的完整核心卖点。

## 页面主卖点

- 中国内地可用
- 漫游流量低至 `3.5 CNY/G`
- 香港 IP / 原生国外 IP
- 香港号码可接短信
- 免国内实名流程
- 24 小时自动发货
- 支持热点共享
- 支持 eSIM 直装，也可提示不支持 eSIM 的设备搜索 `eSIM 转实体卡`
- 多出口原生 IP：香港、澳门、台湾、日本、韩国、美国等
- 更高隐私弹性，减少本地网络侧访问痕迹
